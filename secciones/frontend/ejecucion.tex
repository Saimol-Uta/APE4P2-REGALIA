\par\medskip\noindent\textbf{Módulo Web --- Tienda en línea y panel de rutas (27 casos: CP-028 a CP-054).}\par\smallskip
En esta sección se presentan los resultados de la ejecución de los 27 casos de prueba del módulo web
(\texttt{CP-028} a \texttt{CP-054}). Los casos abarcan la tienda en línea (historial de pedidos,
cobertura de entrega, horario y regresión del proceso de compra) y el panel administrativo de
planificación de rutas con el motor vial.

Las pruebas se ejecutaron sobre la aplicación web React (\texttt{frontend-web-logistica}) conectada
al backend NestJS local, con una base de datos PostgreSQL~16 aislada y el motor vial OSRM desplegado
en Docker con la cartografía de Ecuador. Cada caso se automatizó con un script de Playwright que opera
la interfaz real del mismo modo que lo haría un usuario y, en paralelo, consulta la API con el mismo
token de sesión. De esta forma se contrastó lo que muestra la pantalla con lo que registra el servidor.

En los casos de rechazo se compararon el stock del producto, el saldo de la tarjeta simulada y el
número de pedidos antes y después de cada intento. Un caso solo se consideró exitoso cuando, además
de mostrar el mensaje correcto, no dejó efectos parciales en el sistema. Todos los datos utilizados
(clientes, productos, repartidores y pedidos) son sintéticos y se crearon exclusivamente para esta
ejecución. Las configuraciones modificadas durante las pruebas (cobertura y horario de la tienda) se
restauraron a sus valores originales al finalizar cada grupo.
